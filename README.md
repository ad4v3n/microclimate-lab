# Виртуальный лабораторный комплекс «Исследование и гигиеническая оценка микроклимата рабочей зоны»

Интерактивное веб-приложение для проведения лабораторной работы по дисциплинам **«Охрана труда»**, **«Безопасность жизнедеятельности (БЖД)»** и **«Производственная санитария и гигиена»**.

Соответствует действующим санитарным правилам и нормам **СанПиН 1.2.3685-21** («Гигиенические нормативы и требования к обеспечению безопасности и (или) безвредности для человека факторов среды обитания») и **ГОСТ 12.1.005-88**.

---

## 🚀 Быстрый запуск

Приложение является полностью автономным SPA (Single Page Application) и не требует установки сторонних библиотек.

### Вариант 1 (рекомендуемый для Windows)
Просто дважды щёлкните на файл:
```text
start.cmd
```
Скрипт автоматически запустит локальный сервер или откроет лабораторную в вашем браузере по умолчанию.

### Вариант 2 (напрямую в любом браузере)
Откройте файл `index.html` двойным кликом мыши в любом современном браузере (Chrome, Edge, Firefox, Яндекс.Браузер).

### Вариант 3 (через Python)
```bash
python -m http.server 8085
```
Затем перейдите по адресу: [http://localhost:8085](http://localhost:8085)

## 🎯 Цели и задачи лабораторной работы

1. Ознакомиться с приборами для измерения параметров микроклимата:
   - аспирационным психрометром МВ-4М (Ассмана);
   - крыльчатым анемометром АСО-3;
   - шаровым зачерненным термометром для оценки лучистого тепла.
2. Научиться рассчитывать относительную влажность воздуха по психрометрической формуле Шпрунга.
3. Научиться определять скорость движения воздуха по тарировочному графику анемометра.
4. Провести гигиеническую оценку условий труда по СанПиН 1.2.3685-21 в зависимости от категории тяжести работ по энерготратам ($Iа$ – $III$) и периода года (холодный/теплый).
5. Установить класс условий труда (1 — Оптимальный, 2 — Допустимый, 3.1–3.3 — Вредный).
6. Разработать и смоделировать инженерно-технические мероприятия по охране труда для нормализации микроклимата.
7. Сформировать и распечатать готовый лабораторный отчет.
8. Пройти проверку знаний во встроенном экспресс-тесте к защите.

## 🔬 Состав виртуального стенда

### 1. Аспирационный психрометр Ассмана
- **Сухой термометр ($t_{сух}$)**: измеряет истинную температуру воздуха.
- **Влажный термометр ($t_{вл}$)**: резервуар обернут смоченным батистом; испарение воды отнимает теплоту фазового перехода, понижая показания.
- **Аспиратор (вентилятор)**: протягивает воздух с фиксированной скоростью **2.0 м/с**, исключая случайные сквозняки.
- **Двойные никелированные трубки**: экранируют термометры от теплового излучения окружающих предметов.

**Формула Шпрунга для расчета упругости водяного пара:**
$$e = E_{вл} - A \cdot P \cdot (t_{сух} - t_{вл})$$
где:
- $e$ — фактическая упругость (парциальное давление) водяного пара, гПа;
- $E_{вл}$ — максимальная упругость насыщенного пара при температуре влажного термометра, гПа;
- $A = 0.000662$ — психометрический коэффициент для аспиратора;
- $P$ — барометрическое давление ($1013.25$ гПа / $760$ мм рт. ст.);
- $(t_{сух} - t_{вл})$ — психрометрическая разность температур, °C.

**Относительная влажность воздуха:**
$$\varphi = \frac{e}{E_{сух}} \cdot 100\%$$

---

### 2. Крыльчатый анемометр АСО-3
- Предназначен для замера малых скоростей воздуха от **0.1 до 5.0 м/с**.
- Интерактивный секундомер на 20 секунд:
  $$n_{сек} = \frac{n_2 - n_1}{\tau}$$
- Расчет скорости $v$ (м/с) по тарировочной зависимости прибора.

---

### 3. Тепловое облучение и шаровой термометр
- Оценка радиационной температуры $t_{шар}$ в горячих цехах (у печей, сварочных постов).
- Определение индекса тепловой нагрузки среды:
  $$ТНС = 0.7 \cdot t_{вл} + 0.3 \cdot t_{шар}$$

## 🛠 Инженерные меры защиты (нормализация)

Студент может интерактивно активировать защитные решения:
- **Общеобменная приточно-вытяжная вентиляция с подогревом/рекуперацией**;
- **Воздушно-тепловая завеса у ворот** (устраняет сквозняк);
- **Кондиционирование и охлаждение воздуха**;
- **Теплозащитные отражающие экраны / водяные завесы** (снижают до 85% лучистого тепла);
- **Увлажнители воздуха**;
- **Регламентированные технологические перерывы в комнатах отдыха**.

Приложение мгновенно пересчитывает физические показатели и показывает, как условия труда переводятся из **Вредных (3.1–3.3)** в **Допустимые (2)** или **Оптимальные (1)**.
